## 数据说明

- 收录标准：GitHub 公开仓库、免费开源、与达芬奇工作流直接相关
- 收录流程：AI 辅助全量检索 GitHub（关键词 + topic 遍历）→ 人工核验 → 按分类合并
- Star 数为采集时快照，仅供参考，不代表项目活跃度
- 全部数据集中在 `index.html` 内的 `DATA` 数组中，增删条目只需编辑该数组，页面自动重算总数与排序

## 本地使用 / 二次部署

```bash
git clone https://github.com/akahoz94/hoz-davinci-plugins.git
```

直接双击打开 `index.html` 即可使用，也可部署到任意静态托管（GitHub Pages、EdgeOne、COS 等）。
